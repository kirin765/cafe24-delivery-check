# adapters

점검 입력을 도메인 타입으로 바꾸는 어댑터입니다. 현재 구현된 것은 수동 CSV 어댑터 하나뿐입니다.

| adapter | 상태 | 조건 |
|---|---|---|
| `manual-csv` | 구현 | 운영자가 정리한 상품·규칙·근거 CSV를 브라우저에서만 파싱 |
| `official-export` | 미구현 | 제공 서비스의 공식 export/API 존재·권한·규칙 의미 확인 후 |
| `cafe24-api` | 미구현 | 주문·상품 조회만으로 외부 발송 설정을 알 수 없음. 최소 scope·launch/OAuth 검증 후 |

새 어댑터를 추가할 때 지킬 것:

- 데이터 접근이 불가능한데 자동 점검이 되는 것처럼 UI를 만들지 않는다.
- 타 서비스의 비밀키·세션 쿠키·개인 다운로드 링크를 입력으로 받지 않는다.
- 외부 규칙을 변경하지 않는다. 읽기 전용으로만 대조한다.
- 몰(tenant) 격리를 유지하고, 서로 다른 몰의 같은 상품 번호를 매칭하지 않는다.
